# Python Assignment Projects

This repository contains two beginner-friendly Python programs.

## Calculator

Run the calculator:

```cmd
python calculator.py
```

Enter an expression such as `12 + 5`. Supported operators are `+`, `-`, `*`,
and `/`. Enter `q` to quit.

## Student Grade Manager

Run the grade manager:

```cmd
python grade_manager.py
```

Enter a student's name and mark from 0 to 100. Grades are assigned as follows:

| Mark | Grade |
| --- | --- |
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 0–59 | F |

Both programs use only the Python standard library.
